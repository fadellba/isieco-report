# Application Web ISI-Eco Report

Application React 19 + Vite 8 pour le back-office et la page publique `/telecharger`.

Les styles utilisent Tailwind CSS 3.4.17 via PostCSS. Les composants et pages doivent privilégier les classes utilitaires dans `className` ; les règles CSS globales doivent rester limitées à la base et aux tokens globaux.

```bash
pnpm dev:web
```

Les routes métier et l'authentification Supabase ne sont pas encore implémentées.
