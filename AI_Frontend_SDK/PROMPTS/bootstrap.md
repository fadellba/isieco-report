# Bootstrap Prompt

## Mission

Initialiser une nouvelle mission conformément au framework AI SDK.

---

## Instructions

Exécuter intégralement le Workflow **00 — Bootstrap** avant toute autre action.

---

## Documents obligatoires

Lire dans l'ordre :

1. AI_CONTEXT.md
2. MANIFEST.md
3. README.md
4. Le document correspondant à votre rôle dans `AGENTS/`
5. Tous les documents de `PROJECT_RULES/`
6. Le Workflow `00-bootstrap.md`

---

## Vérifications obligatoires

Avant de commencer, vérifier que :

* la mission est clairement définie ;
* le périmètre est connu ;
* les dépendances sont disponibles ;
* les documents nécessaires existent ;
* aucun blocage n'empêche l'exécution.

---

## En cas de blocage

Si une dépendance est absente ou si la mission est ambiguë :

* arrêter immédiatement l'exécution ;
* produire un rapport de blocage ;
* ne générer aucun code, aucune spécification et aucun document incomplet.

---

## Résultat attendu

À la fin du bootstrap, produire uniquement :

* un résumé de la mission ;
* les dépendances identifiées ;
* les livrables attendus ;
* la décision :

  * Mission autorisée ; ou
  * Mission bloquée.

Ne commencer aucune autre activité tant que le bootstrap n'est pas validé.
