# AI Frontend SDK - ROADMAP

Version actuelle : 1.1.0

---

# Vision

Faire évoluer AI Frontend SDK vers un environnement complet de conception et développement frontend assisté par IA.

---

# Version 1.x

Objectif :

Stabilisation du framework.

Possibles évolutions :

- enrichissement des templates ;
- amélioration des prompts ;
- nouveaux agents spécialisés ;
- nouveaux workflows ;
- meilleure automatisation documentaire.

---

# Version 1.2.x (immédiat)

Objectif :

Valider la couche d'orchestration sur un projet réel.

Axes :

- test de dogfooding (`OUTPUT/mission-dogfood-*.md`) : mission complète pilotée par MASTER.md depuis une instruction unique ;
- complétion du Design System (composants + maquettes Figma) ;
- implémentation frontend de référence (espace Citizen / Agent / Admin).

---

# Version 2.x

Objectif :

Augmenter l'automatisation.

Axes possibles :

- génération assistée d'architecture ;
- validation automatique des documents ;
- analyse automatique de cohérence ;
- intégration outils de développement.

---

# Version 3.x

Objectif :

Plateforme complète de développement assisté IA.

Axes possibles :

- orchestration multi-agents ;
- mémoire projet avancée ;
- génération contrôlée de composants ;
- pipeline complet conception → code → validation.

---

# Principe d'évolution

Toute évolution doit respecter :

- compatibilité descendante lorsque possible ;
- documentation obligatoire ;
- validation qualité ;
- conservation des principes fondamentaux.
