# ISI-Eco Report

Plateforme de signalement citoyen et de suivi des interventions environnementales.

Monorepo initial pour les applications web (React/Vite/Tailwind), mobile (React Native/Expo) et API (NestJS/Prisma/PostgreSQL).

Le modèle Prisma actuel couvre le profil utilisateur et les rôles. La traduction complète des 39 modèles du MLD reste à réaliser.
